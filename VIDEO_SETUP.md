# Video Setup Instructions

## For Landing Page Video:
- Place your landing page video at: `public/videos/landing.mp4`
- This video will play on the initial landing page

## For Main App Video:
- Place your main app background video at: `public/videos/main.mp4`
- This video will play as background in the main quote app

## Video Requirements:
- MP4 format
- Optimized for web (consider file size)
- Loop-friendly content
- Aspect ratio suitable for full-screen background

## Current Setup:
- Landing page shows: App name "Quote Universe", small quote, heart button
- Clicking heart enters the main quote app
- Main app uses single video background with time-based overlays
